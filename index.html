1.1. Основные источники погрешностей

При решении задач численными методами неизбежно возникают погрешности. Рассмотрим основные источники их возникновения.

Виды погрешностей

  • Математическая погрешность — связана с упрощением реальной задачи.
  • Погрешность метода — возникает при замене точного метода приближённым.
  • Погрешность округления — появляется при вычислениях с ограниченной точностью.
  • Неустранимая погрешность — из-за неточности входных данных.

Абсолютная и относительная погрешности

Пусть $x$ — точное значение, $x^*$ — приближённое. Тогда:

$$\Delta x = |x - x^*|$$

$$\delta x = \frac{\Delta x}{|x|} = \frac{|x - x^*|}{|x|}$$
